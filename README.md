# Содержимое репозитория для GitHub Pages

Три файла отсюда кладутся в корень нового публичного репозитория: `remote_config.json`, `index.html`, `.nojekyll`.
Пошаговая инструкция - в `Docs/REMOTE-CONFIG.md`, раздел «GitHub Pages».

`remote_config.json` здесь - пустой безопасный вариант: ничего не закрыто, сообщений и событий нет. Образец с событием - `Docs/remote_config.example.json`.
